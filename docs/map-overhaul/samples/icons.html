Map icon sheet

Point assets are round badges: a dark disc with a light glyph, so they read on bright and dark imagery alike. The glyph says what the thing is. The ring says whether it is working. Lines and areas carry their own colour instead (water blue, power yellow, road tan).

Anatomy of a badge

  1. Glyph. One per asset type, stroke drawn, readable at 16px. Type is never shown by colour, so the set works for colour-blind users and in glare.
  2. Disc. Always dark (the app's panel colour) with a thin black edge, so it separates from any imagery. 28px on the map inside a 44px tap target.
  3. Status ring. Green for running, amber for warning, red for fault, grey dashed for offline. White when the asset has no live data. Faults and warnings also get a corner "!" so they don't rely on colour.
  4. Value chip. One live reading, chosen by the view: flow in Irrigation, kilowatts in Infrastructure. Hidden when zoomed out.

The set

Each type at list size (22px), map size (28px) and selected (40px). Types marked "line" or "area" use the badge in lists, pickers and the detail card, and on the map only at their label point.

States

Live status and selection are separate channels, so a selected pump that is faulting shows both. Status always comes with a word, in the tooltip, the list and the card.

Lines and areas

Every line has a dark casing so it holds up on pale paddocks, and an invisible 22px wide hit line so it can be tapped with a thumb.

Two directions for point colour

The sheet above uses option A. Option B is the common alternative, shown here so you can compare them on the same patch of ground.

A · Recommended Neutral discs, status in the ring. The fault stands out because nothing else on the map is red.

B Discs coloured by domain (water blue, power yellow, access tan) with status as a small dot. Types group at a glance, but a fault is a 7px dot and green or amber status clashes with the domain colours.
